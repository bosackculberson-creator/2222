# 30 帧透明像素前景动画 · 调整版

本文件夹集中存放全部 30 张 PNG：**frame_001.png 至 frame_030.png**，按编号顺序循环播放。

- 原始尺寸：1984 × 793；每帧为 RGBA PNG，透明背景。
- 建议播放：15 FPS，2 秒循环；使用 nearest / point 采样。
- 调整：各簇树叶和灌木错开摆动；适当增加轻晃幅度，旗帜持续起伏，悬挂灯笼与流苏错开运动。
- 建筑、屋顶、栅栏、桥、地面、岩石及灯柱保持固定。
- 所有帧均从原图按整数像素采样，不缩放、不添加模糊或插值颜色。首帧从微风循环中的自然姿态开始。
- 已核对全部相邻帧及第 30 → 1 帧的衔接，可见变化不再集中在少数几帧。
- 下载完整文件夹后打开 preview.html，可播放、暂停或逐帧查看。
- animation.json 提供帧顺序、尺寸和建议播放参数。
