## 动作

五处瀑布的水纹沿重力方向持续下落，落水口保持固定。使用落下时间坐标传递水纹，速度随落差增大：`v(y) = sqrt(v0² + 2gy)`；下部水纹拉长，末端融入原图雾气。循环通过连续供水的周期纹理实现。

天空云层和山谷云雾以不同速度向右漂移，使用双层淡入淡出衔接和移动雾纹。楼阁、桥梁、山体轮廓与镜头保持固定。动画在原画布上合成，没有缩放图片或对整幅画面进行模糊处理。

PNG 保留完整 RGB 色彩；GIF 使用统一调色板，避免逐帧换色造成闪烁。需要游戏引擎导入或原色播放时，请使用 PNG 序列。

## 复现

安装 `Pillow`、`numpy`、`scipy` 后运行：

```sh
python render_animation.py source.png regenerated
```

`animation.json` 包含尺寸、时长、帧编号与源文件 SHA-256。`validation.json` 包含帧数、时长、首尾过渡、固定区域及瀑布下落方向检查。
